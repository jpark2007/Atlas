## 10. Incremental sync — QUEUED (Drew, 09-03), after 1/2/7. Supersedes item 8's "wait"

Measured 09-03 against the live DB (service role, all 11 tables `loadAll` pulls, per user).
`getAll` paginates correctly (1000/page), so no truncation bug. Compressed sizes assume
URLSession's default `Accept-Encoding: gzip`, which Supabase honors and bills on.

| user                      | rows | raw     | gzip on the wire |
|---------------------------|------|---------|------------------|
| heaviest (856 events)     | 900  | 720 KB  | ~45 KB           |
| Drew (256 ev, ~100 tasks) | 350  | 290 KB  | ~31 KB           |
| Jonah                     | 140  | 108 KB  | ~15 KB           |

Timer: `AppState.startBackgroundRefreshTimer` = 300 s, every table, no `since`, runs while
the app is open even if the Mac is idle overnight. Egress math on the free plan's 5 GB/month:
always-open Mac (288 pulls/day) × 45 KB ≈ 390 MB/user/month → ~13 heavy always-on users,
~19 at Drew's size; part-day iOS/Mac use stretches that to ~40-60 students. Every semester
import adds ~200-300 materialized recurring rows per student, so per-user size trends up.

Plan, cheapest first:
1. **Idle pause (do first, ~20 lines, no data risk):** skip the 5-min tick when the Mac has had
   no user input for >10 min (`CGEventSource.secondsSinceLastEventType`) or the window is
   occluded, and pull once on wake/focus. Cuts overnight egress to zero. iOS already stops
   in background.
2. **`since` cursor on `tasks` and `events` only** (95% of bytes): `updated_at=gt.<cursor>`
   in AtlasDB, merge into the snapshot instead of replace. Requires deletes to be visible:
   add `deleted_at` soft-delete to those two tables (migration) and have the cursor pull
   include them; the client drops them locally. Hard-delete via a nightly cron after 30 days.
   Other 9 tables stay full-pull (they total <10 KB compressed).
3. Fallback that needs no code: Supabase Pro ($25/mo) = 250 GB egress, 50× headroom.
   If signups outrun step 2, buy time with this.
Tests: cursor merge (upsert + tombstone drop) as a pure AtlasCore function.
